# Week 2 Day 2 – JSON Prompting for Tamil Visuals

## Objective
To create a reusable JSON prompt template for generating
culturally authentic Tamil-themed images and videos.

## Cultural Theme
- Region: Chettinad, Tamil Nadu
- Occasion: Margazhi festival
- Subject: Tamil woman drawing kolam
- Clothing: Kanchipuram silk saree
- Architecture: Chettinad traditional courtyard

## Image Experiments

### Image 1 – Base Template
Original JSON template without modifications.

### Image 2 – Golden Hour
Changed only setting.time_of_day
from Early morning to Golden hour.

### Image 3 – Close-up
Changed only camera.shot
from Wide shot to Close-up.

## Video Experiment
Added motion fields:
- Subject motion: Drawing kolam
- Camera movement: Slow dolly-in
- Duration: 5 seconds

## Learning Outcomes
1. Understanding JSON prompting.
2. Creating reusable JSON templates.
3. Controlling image generation using individual fields.
4. Understanding camera, lighting and colour specifications.
5. Extending JSON prompts for video generation.
